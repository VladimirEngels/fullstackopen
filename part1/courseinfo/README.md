# courseinfo

Упражнения 1.1 - 1.5

Приложение показывает название курса, его части с количеством заданий и сколько всего заданий.

Сначала всё было в App, потом разбил на компоненты Header, Content, Part и Total. Данные о курсе хранятся в одном объекте course и передаются через props.

## Как запустить

```
npm install
npm run dev
```

Потом открыть http://localhost:5173
