# unicafe

Упражнения 1.6 - 1.11

Приложение для сбора отзывов для кафе. Есть три кнопки: good, neutral, bad. После нажатия считается статистика:
- сколько всего отзывов
- среднее (good = 1, neutral = 0, bad = -1)
- процент положительных

Пока никто не нажал кнопку, пишется "No feedback given". Статистика выводится в таблице.

Компоненты: Button, Statistics, StatisticLine. Состояние хранится в App через useState.

## Как запустить

```
npm install
npm run dev
```

Потом открыть http://localhost:5173
