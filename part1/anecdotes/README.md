# anecdotes

Упражнения 1.12 - 1.14

Показывает случайный анекдот про программирование. Кнопка "next anecdote" выбирает другой анекдот, кнопка "vote" добавляет голос.

Голоса хранятся в массиве, при голосовании делаю копию массива и меняю копию (состояние напрямую менять нельзя).

Внизу показывается анекдот, у которого больше всего голосов.

## Как запустить

```
npm install
npm run dev
```

Потом открыть http://localhost:5173
