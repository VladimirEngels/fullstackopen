# bloglist-frontend

Упражнения 5.1 - 5.16

Фронтенд для списка блогов на React. Работает с бэкендом из part4/bloglist-backend.

## Запуск

1. В part4/bloglist-backend запустить базу (npm run db) и сервер (npm run dev)
2. Здесь npm install и npm run dev

В vite.config.js настроен proxy, запросы на /api уходят на localhost:3003.

## Что умеет

- Вход по логину и паролю. Пользователь сохраняется в localStorage, поэтому после перезагрузки страницы не нужно входить заново. Есть кнопка logout
- Добавление блога. Форма спрятана в компоненте Togglable и открывается кнопкой create new blog, после добавления снова прячется
- Уведомления сверху: зелёные при успешном действии, красные при ошибке (например неправильный пароль)
- У каждого блога видно только название и автора, кнопка view показывает url, лайки и имя пользователя, который добавил блог
- Кнопка like увеличивает количество лайков (PUT запрос на бэкенд)
- Блоги отсортированы по количеству лайков, больше лайков сверху
- Кнопка remove видна только тому, кто добавил блог, перед удалением спрашивается подтверждение

## Компоненты

- Blog - один блог с кнопками view/hide, like, remove
- BlogForm - форма добавления, у неё своё состояние для полей
- LoginForm - форма входа
- Notification - уведомление
- Togglable - показывает и прячет содержимое, наружу через ref отдаёт toggleVisibility

Для Togglable прописаны PropTypes (buttonLabel обязательный). React 19 больше не проверяет propTypes сам, так что это скорее описание того, какие props нужны компоненту.

## Линтер и тесты

- npm run lint - ESLint, конфиг в eslint.config.js
- npm test - тесты компонентов на Vitest и React Testing Library

Тесты:

- BlogForm.test.jsx - форма вызывает createBlog с правильными данными

E2E тесты лежат в соседней папке bloglist-e2e.
