# bloglist-e2e

Упражнения 5.17 - 5.23

E2E тесты для списка блогов на Playwright.

## Запуск

1. npm install
2. npx playwright install chromium (один раз, скачивает браузер)
3. npm test

В playwright.config.js прописаны три webServer: база (npm run db) и бэкенд в тестовом режиме (npm run start:test) из part4/bloglist-backend, и фронтенд (npm run dev) из bloglist-frontend. Playwright запускает их сам и останавливает после тестов. Если они уже запущены, используются запущенные. В bloglist-frontend и part4/bloglist-backend перед этим нужно сделать npm install, а в бэкенде должен быть файл .env.

Перед каждым тестом база очищается запросом POST /api/testing/reset. Этот маршрут есть на бэкенде только когда он запущен с NODE_ENV=test. Потом через API создаются два пользователя.

## Тесты

- 5.17 по умолчанию показывается форма входа
- 5.18 вход с правильным паролем работает, с неправильным показывается красное сообщение об ошибке
- 5.19 после входа можно создать блог
- 5.20 блогу можно поставить лайк
- 5.21 пользователь, который добавил блог, может его удалить
- 5.22 кнопку remove видит только тот, кто добавил блог
- 5.23 блоги отсортированы по лайкам, больше лайков сверху

Общие действия (вход, создание блога, лайки) вынесены в tests/helper.js.
