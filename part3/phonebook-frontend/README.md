# phonebook-frontend

Упражнения 3.9 и 3.11

Телефонная книга из части 2, только теперь она работает с моим бэкендом из папки phonebook-backend, а не с json-server.

В services/persons.js адрес поменял на /api/persons. В vite.config.js настроил proxy, чтобы при npm run dev запросы на /api уходили на localhost:3001. Для этого бэкенд должен быть запущен.

Изменение номера у уже существующего контакта пока не работает, потому что на бэкенде ещё нет PUT запроса.
