# phonebook-backend

Упражнения 3.1 - 3.9, 3.11

Бэкенд для телефонной книги на Node.js и Express. Запуск через npm start, для разработки npm run dev (сервер перезапускается сам при изменении файлов). Сервер работает на порту 3001.

- GET /api/persons - список всех контактов
- GET /info - сколько людей в книге и текущее время
- GET /api/persons/:id - один контакт, если такого id нет то 404
- DELETE /api/persons/:id - удаление контакта, отвечает 204
- POST /api/persons - добавление контакта, id генерируется случайно через Math.random

При добавлении проверяется что есть имя и номер, и что такого имени ещё нет в книге. Если что-то не так, сервер отвечает 400 и сообщением об ошибке, например { "error": "name must be unique" }.

Запросы логируются через morgan. Сделал свой токен body, чтобы в логе было видно тело POST запроса, у остальных запросов он пустой.

В папке requests лежат запросы для проверки через REST Client в VS Code.

Бэкенд также отдаёт собранный фронтенд из папки dist через express.static. Команда npm run build:ui собирает фронтенд из папки phonebook-frontend и копирует dist сюда. После этого npm start и приложение открывается на http://localhost:3001.

Упражнение 3.10 (выкладка в интернет) не делал, всё запускается локально.
