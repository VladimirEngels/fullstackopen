# phonebook-backend

Упражнения 3.1 - 3.9, 3.11 - 3.20, 3.22

Бэкенд для телефонной книги на Node.js, Express и MongoDB (через mongoose). Сервер работает на порту 3001.

## Запуск

1. npm install
2. Скопировать .env.example в .env
3. npm run db - запускает MongoDB локально (пакет mongodb-memory-server, сам скачивает MongoDB при первом запуске). Данные хранятся в папке mongo-data, она не попадает в git
4. В другом терминале npm start, для разработки npm run dev (сервер перезапускается сам при изменении файлов)

Вместо облачной MongoDB Atlas из курса использую локальную базу, адрес лежит в .env в MONGODB_URI.

## Маршруты

- GET /api/persons - список всех контактов
- GET /info - сколько людей в книге и текущее время
- GET /api/persons/:id - один контакт, если такого id нет то 404
- DELETE /api/persons/:id - удаление контакта, отвечает 204
- POST /api/persons - добавление контакта
- PUT /api/persons/:id - изменение номера, если такого id нет то 404

Данные проверяются в схеме mongoose (models/person.js), и при добавлении, и при изменении:

- имя обязательно и не короче 3 символов
- номер обязателен, не короче 8 символов и в формате две или три цифры, дефис, цифры (например 09-1234556 или 040-22334455)

Если данные не прошли проверку, сервер отвечает 400 и текстом ошибки от mongoose.

Ошибки передаются через next в errorHandler (ValidationError и CastError отвечают 400). Если id неправильного формата, сервер отвечает 400 и { "error": "malformatted id" }. На неизвестные адреса отвечает 404 { "error": "unknown endpoint" }.

Запросы логируются через morgan. Сделал свой токен body, чтобы в логе было видно тело POST запроса, у остальных запросов он пустой.

В папке requests лежат запросы для проверки через REST Client в VS Code.

## ESLint

Конфиг в eslint.config.mjs, проверка командой npm run lint. Правила: отступ 2 пробела, одинарные кавычки, без точек с запятой, eqeqeq, без пробелов в конце строк.

## mongo.js

Скрипт для работы с базой из командной строки (база должна быть запущена через npm run db).

- node mongo.js - выводит все контакты
- node mongo.js "Arto Hellas" 040-123456 - добавляет контакт

В курсе первым аргументом передаётся пароль от Atlas, у меня база локальная, поэтому пароль не нужен.

## Фронтенд

Бэкенд также отдаёт собранный фронтенд из папки dist через express.static. Команда npm run build:ui собирает фронтенд из папки phonebook-frontend и копирует dist сюда. После этого приложение открывается на http://localhost:3001.

Упражнение 3.10 (выкладка в интернет) не делал, всё запускается локально.
