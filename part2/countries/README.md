# countries

Упражнения 2.18 - 2.20

Поиск стран по названию. Список всех стран загружается один раз из https://studies.cs.helsinki.fi/restcountries/api/all, дальше фильтрация идёт на клиенте:

- больше 10 совпадений — просьба уточнить запрос;
- от 2 до 10 — список стран с кнопкой show;
- одно совпадение (или нажата show) — столица, площадь, языки, флаг и погода в столице.

Погода берётся из OpenWeatherMap по названию столицы. Ключ API не хранится в коде, он передаётся через переменную окружения VITE_SOME_KEY. Можно положить его в файл `.env` (он в .gitignore):

```
VITE_SOME_KEY=ваш_ключ
```

или задать при запуске (PowerShell):

```
$env:VITE_SOME_KEY="ваш_ключ"; npm run dev
```
