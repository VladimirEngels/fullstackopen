# courseinfo

Упражнения 2.1 - 2.5

Продолжение courseinfo из первой части. Теперь курсов несколько, они хранятся в массиве courses и выводятся через map.

Компонент Course вынесен в отдельный модуль components/Course.jsx, внутри него Header, Content, Part и Total. Части курса рендерятся через map с key = id, а сумма заданий считается через reduce, так что количество частей может быть любым.
