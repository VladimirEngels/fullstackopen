# phonebook

Упражнения 2.6 - 2.17

Телефонная книга: можно добавлять людей с номерами, искать по имени, менять номер и удалять записи. Данные хранятся на json-server.

Запуск (в двух терминалах):

```
npm run server
npm run dev
```

Всё состояние и обработчики лежат в App, а отображение разбито на компоненты Filter, PersonForm, Persons и Notification. Запросы к серверу вынесены в services/persons.js.

Если имя уже есть в книге, приложение спрашивает, заменить ли номер, и отправляет PUT. Перед удалением тоже спрашивает подтверждение. После добавления или изменения номера показывается зелёное уведомление на 5 секунд, при ошибке (например, запись уже удалили в другой вкладке) — красное.
