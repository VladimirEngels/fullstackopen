# phonebook

Упражнения 2.6 - 2.17

Телефонная книга. Можно добавлять имя и номер, искать по имени, удалять и менять номер.

Данные лежат в db.json, запускаю json-server командой npm run server, а само приложение через npm run dev.

Запросы к серверу в файле services/persons.js. После добавления показывается зелёное сообщение, при ошибке красное.
